# Agent instructions

Start with the [repository map](/MAP.md) and open the document that owns your
task before searching folders.

- This is a personal app: no App Store, no sandbox, no distribution concerns.
- Full Xcode is not installed; build with Swift Package Manager through
  `scripts/build-app.sh`, as [development](/docs/development.md) describes.
- Update the documents your change affects in the same change.
